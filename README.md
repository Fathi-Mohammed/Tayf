# طيف — Tayf

*[In English](README.en.md)*

تضغط **Ctrl + Space** وإنت في أي برنامج → تطلع طبقة سودا شفافة فوق الشاشة
→ تشوف تاسكاتك على Jira وتغيّر حالتها أو تضيف تاسك جديدة → تضغط **Esc** → ترجع لشغلك.

من غير ما نفتح المتصفح، ومن غير ما نسيب مكاننا.

## ليه؟

كل مرة عايزين نشوف «أنا ورايا إيه؟» أو ننقل تاسك، أو المدير يطلب تاسك جديدة
ونحتاج نضيفها بسرعة — لازم نفتح المتصفح وندوّر ونستنى Jira يحمّل.
الوقت مش المشكلة، المشكلة إن التركيز بيتقطع.

## الاختصارات

| | |
|---|---|
| `Ctrl + Space` | اللستة — تاسكاتي |
| `Ctrl + Shift + Space` | إضافة تاسك على طول |

على الماك `⌥ Space` و `⌥ ⇧ Space` — لأن `Ctrl+Space` هناك محجوز لتبديل لغة الكيبورد.

**في اللستة:** `↑` `↓` تنقل · **`→` خيارات التاسك** (عرض · تعديل · غيّر الحالة ·
افتح في جيرا · انسخ المفتاح) · `Tab` غيّر الحالة · `Enter` عرض · `Esc` اقفل.
وفوق فيه فلاتر — الكل · النهاردة · متأخرة · شغال عليها — على `Alt+1` لـ `Alt+4`.
والبحث بيفلتر بالمفتاح والعنوان والنوع والبورد.

**الإضافة:** عنوان → `Enter` وخلاص (بيستخدم آخر بورد ونوع). ولو حبيت تظبط:
البورد · النوع · مسندة لـ · التسليم · الوقت المتوقع · الوصف.
التسليم بيفهم `النهاردة` و `بكرة` و `الخميس` و `+3` والتاريخ، والوقت رقم لوحده = دقايق.

**في صفحة التاسك** (`Enter` على أي تاسك): الوصف وآخر ٥ كومنتات، و`C` بينط بيك لخانة
الكومنت — اكتب و`Ctrl+Enter` يبعته، ويظهر تحت على طول من غير ما تفتح جيرا.

**المحرر** — في الكومنت وفي الوصف، وفوقه صف أزرار زي اللي في جيرا:

| | |
|---|---|
| `Ctrl+B` · `Ctrl+I` · `Ctrl+U` | عريض · مايل · تحته خط |
| `Ctrl+Shift+S` · `Ctrl+Shift+M` | مشطوب · كود |
| `Ctrl+Shift+8` · `7` · `6` | نقط · ترقيم · تشيك ليست |

ونفس الاختصارات بتاعة جيرا بالظبط. وتقدر تكتب بدل ما تدوس: `- ` نقطة، `1. ` ترقيم،
`[] ` تشيك ليست، `# ` عنوان، `> ` اقتباس، و`````` بلوك كود. والتيكات في التشيك ليست
بتتقفل بالضغط عليها.

**والمنشن:** `@` بتفتح لستة الأسامي — تختار واحد فيبقى منشن حقيقي والشخص يتبلّغ،
والمسافة في الاسم مش بتكسره. وتحت الخانة فيه أزرار سريعة بأسامي الناس زي جيرا.
الوصف اللي فيه حاجات المحرر مايعرفهاش (جدول · صورة · لوحة) بيتقفل بدل ما الحفظ يمسحها.

**اجتماع سريع:** `Ctrl+M` وإنت في اللستة → نفس فورمة الإضافة بس جاهزة: العنوان
`Meeting` · الاستلام والتسليم النهاردة · ساعة وقت · وآخر بورد عملت عليها تاسك.
كلها خانات عادية تعدّلها زي ما إنت عايز — دي قيم افتراضية بس، عشان الاجتماع اللي
خد ساعة من يومك يتسجّل بـ `Enter` واحدة.

## المظهر

من الإعدادات ← **المظهر** (`Ctrl+4`): فاتح ولا غامق — أو سايبه يمشي ورا الويندوز ·
خمس ثيمات من VS Code (Tokyo Night · One Dark Pro · Dracula · Nord · GitHub)، كل
واحد بوجهين فاتح وغامق · خطين مرفقين مع خط الجهاز · وحجم الطبقة من ٩٠٪ لـ ١٣٠٪.

كل المقاسات بتيجي من طبقة توكنز واحدة مبنية على سلّم macOS من الـ
[Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/typography)،
والثيم بيغيّر الألوان بس — فالإيقاع ثابت مهما بدّلت.

## أهم حاجة اتحلّت: مشكلة الـ 3 بوردات

المشروع الواحد ممكن يكون عليه كذا بورد، وكل بورد بيفلتر بشرط مختلف.
الأداة **بتقرا فلتر البورد وتفهم لوحدها** المطلوب وبتحطه في التاسك، وبتوريك
هتعمل إيه قبل ما تعمله. مثال حقيقي:

| البورد | الأداة بتحط |
|---|---|
| FPE - React | `Labels = React` |
| FPE - Product Design | `Task Type = UI Task` |
| FPE - Tech | مفيش — ده الافتراضي |

ده شغال على أي بورد، مش متبرمج على مشروع معيّن.

## التشغيل

```bash
npm install
cp config.example.json config.json   # املا الموقع والإيميل والتوكن
npm start
```

على Ubuntu 24.04، سطّب مكتبات Electron المطلوبة الأول:

```bash
sudo apt update
sudo apt install libnspr4 libnss3 libasound2t64
```

التوكن بتعمله من
[id.atlassian.com/manage-profile/security/api-tokens](https://id.atlassian.com/manage-profile/security/api-tokens).
وممكن كمان تحطه من جوه الأداة نفسها: أيقونة الساعة ← الإعدادات.

**بياناتك على جهازك بس.** مفيش سيرفر، ومفيش تتبّع. التوكن بيتحفظ في مجلد بيانات
التطبيق وعمره ما بيخرج من جهازك غير لجيرا نفسه.

عايز نسخة مستقلة؟ `npm run dist`. على لينكس استخدم
`npm run dist:linux` عشان تعمل AppImage.

## المشروع مبني إزاي

| | |
|---|---|
| الستاك | Electron · جافاسكريبت عادية · من غير خطوة بناء |
| المنصات | ويندوز · ماك · لينكس |
| الخطوط | Cairo للعربي · Inter للاتيني — متسنّدين في `assets/fonts/` |
| جيرا | Jira Cloud · دخول بـ API Token |
| الاختبارات | `node --test` من غير أي مكتبات |

الكود مقسّم لطبقات: الواجهة مبتعرفش إن جيرا موجود أصلاً، وكل حاجة بتخص جيرا
محبوسة في `src/providers/jira/`. التفاصيل في
[docs/architecture.ar.md](docs/architecture.ar.md).

**الكود من غير كومنتات عن قصد** — المفروض يشرح نفسه. والمعرفة اللي الكود
مش بيقدر يعبّر عنها (جيرا بيكدب فين، والفروق بين ويندوز والماك) في
[docs/jira-quirks.ar.md](docs/jira-quirks.ar.md). اقراه قبل ما تعدّل.
